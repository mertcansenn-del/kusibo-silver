MONO LINK mobil duzeltme paketi. index.html ve .webp dosyalarini GitHub deponuzun ANA dizinine yukleyin, mevcut index.html dosyasini degistirin. Degisiklikler: sabit menu icin baslik kaydirma payi, QR menu metin kontrasti, urun kartlarina ornek gorseller, mobil menu nokta temizligi ve Urun Galerisi baglantisi. Gorseller temsilidir; 2/3 NFC alanlari fotograflarda dogrulanmamistir. Canli siteye otomatik yukleme bu paketle yapilmadi.
